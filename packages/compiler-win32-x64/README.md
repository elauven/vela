# @govela/compiler-win32-x64

The Vela compiler and language server binaries for win32-x64. Install
`@govela/compiler`, which depends on this package for this platform only.

The release workflow builds the binaries into `bin/vela.exe` and
`bin/vela-lsp.exe`; the manifest is generated by the compiler
repository; do not edit.
