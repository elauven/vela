# @govela/app-win32-x64

The `vela-app` binary of [Vela App](https://github.com/elauven/vela/blob/main/docs/VELA_APP.md)
for win32-x64. It is an optional dependency of `@govela/app`, which
installs it on this platform only and runs it as `vela-app`; do not
depend on it directly.

Generated by the compiler repository (`app/npm_package_test.go`); the
binary is built by the release workflow of the app layer.
